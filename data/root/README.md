# Example ROOT input

`ntuple1616.root` contains a compact selection of complete events from the original
run 1616. No per-hit cuts, remapping, or synthetic values were applied to this file.
See `../example_provenance.json` for exact event IDs, counts, selection and checksums.

Additional ROOT inputs in this directory are ignored by Git. Do not replace the
tracked compact example with the full original file when preparing a commit.
